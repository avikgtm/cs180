Colorizing the Prokudin-Gorskii Photo Collection

CS180 — Project 1

by Avik Gautam

Overview

Sergei Prokudin-Gorskii photographed the Russian Empire in the early 1900s by exposing three glass plates of the same scene through red, green, and blue filters. Digitized, each plate is a single grayscale image stacked in three bands (B, G, R from top to bottom). If you manually attempt to stack the bands, you receive a misaligned image. The project below reconstructs the color photo by running an alignment program on the digitized version of the filters.

Approach

Single-scale search For small files, I used a single-scale search using NCC and border-cropping. Since the files were smaller, I could justify using a 31-length window (-15 -> +15). This means I was testing a total of 961 (31 x 31) offsets. To pick which offset worked best I used NCC (see ncc() in the code block below). NCC takes the image as a 2D numpy array and mean-centers it by subtracting each pixel from the mean of the whole image. It then sums the product of the mean-centered arrays and divides that by the product of the normalized mean-centered array. This gives us a score on the range [-1, 1], with higher values corresponding with more correlated images. For single-scale search (align()), I chose the offset with the highest NCC score to align the images.

Pyramid Alignment On images with larger dimensions, the 15 pixel offset window may not be enough to correctly align the images. To mitigate this issue, I used pyramid alignment. Pyramid alignment scales down the image to a lower resolution, aligns based on this resolution, and then converts it back to the original resolution. This allows us to run our alignment on high resolution images without having to iterate over a much larger window. The pyramid_align() function achieves this by scaling down both the image and reference, and recursively calls the pyramid_align() function on these new versions. The base case simply runs an alignment with the original 15 pixel offset window. Once the recursive call returns, the function runs an alignment on a smaller window to make minor corrections due to the lower resolution.

Border Cropping One issue I noticed while attempting to align the images was poor cropping of the filters border from the initial scan. This caused my ncc() function to hallucinate a higher score based on the border's alignment, whereas the actual picture was not well aligned. To mitigate this issue, I implemented a crop_border() function that crops the border of the passed in image by 10%. This is used directly in the align() function, which is also used within the pyramid_align() function, allowing each scoring to be on a better cropped image. 

def ncc(im1, im2):
    mc1 = im1 - np.mean(im1)
    mc2 = im2 - np.mean(im2)
    return np.sum(mc1 * mc2) / (np.linalg.norm(mc1) * np.linalg.norm(mc2))

def align(im, ref, window=15):
    crop_im = crop_border(im)
    crop_ref = crop_border(ref)
    best_ncc = -np.inf
    dx, dy = 0, 0
    for x in range(-window, window+1):
        x_roll = np.roll(crop_im, x, axis=1)
        for y in range(-window, window+1):
            curr_ncc = ncc(np.roll(x_roll, y, axis=0), crop_ref)
            if curr_ncc > best_ncc:
                best_ncc = curr_ncc
                dx = x
                dy = y
    return (dy, dx)

def crop_border(im, pct=10):
    crop_y = int(round(im.shape[0] * (pct/100.0)))
    crop_x = int(round(im.shape[1] * (pct/100.0)))
    return im[crop_y:im.shape[0] - crop_y, crop_x:im.shape[1] - crop_x]

def pyramid_align(im, ref, levels=3, window=15):
    if levels == 0 or im.shape[0] < 100 or im.shape[1] < 100:
        return align(im, ref, window)
    down_im = cv.pyrDown(im)
    down_ref = cv.pyrDown(ref)
    pyr_align = pyramid_align(down_im, down_ref, levels - 1, window)
    al = (pyr_align[0]*2, pyr_align[1]*2)
    alim = np.roll(np.roll(im, al[0], axis=0), al[1], axis=1)
    residual = align(alim, ref, 8)
    return (al[0] + residual[0], al[1] + residual[1])
