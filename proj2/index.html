Part 1.1: Convolutions from Scratch

In this section, I implemented convolution from scratch in two ways: one using four for loops and one using two. I applied both to a grayscale self-portrait with three kernels: a 9×9 box filter, Dx = [1, 0, −1], and Dy = [1, 0, −1]T.

Padding & Flipping

In each case, I first prepped by padding the source image. With each kernel, we want to center the kernel on each individual pixel; however, for edge pixels the kernel can extend past the image bounds. To solve this, we add padding based on the kernel's size: we calculate the height and width of the kernel and pad the original image's edges with zeros. I then flip the kernel and run my for loops. 

flip_kernel = kernel[::-1, ::-1]

kh, kw = kernel.shape
h, w = im.shape

pad_top = kh // 2
pad_bottom = (kh - 1) - pad_top
pad_left = kw // 2
pad_right = (kw - 1) - pad_left

padded = np.zeros(((h + pad_top + pad_bottom), (w + pad_left + pad_right)))
padded[pad_top:pad_top + h, pad_left:pad_left + w] = im
output = np.zeros(im.shape)

Four Loops

In the four-loop case, I run nested for loops over the rows and columns of the original image. Within these loops, I run a second set of nested loops over the kernel's height and width. At each fully nested iteration, I add the current padded image pixel multiplied by the current value of the flipped kernel to a running sum. After iterating through the whole kernel for a given pixel, I set the corresponding output pixel to this sum. 

for i in range(h):
    for j in range(w):
        total = 0
        for u in range(kh):
            for v in range(kw):
                total += padded[i+u, j+v] * flip_kernel[u, v]
        output[i, j] = total

Two Loops

In the two-loop case, I run the same two nested loops over the original image. This time, instead of looping over the kernel itself, I take the kernel-sized slice of the padded image, multiply it elementwise with the flipped kernel, and set the output pixel to the sum of the resulting array. 

for i in range(h):
    for j in range(w):
        output[i, j] = np.sum(padded[i:i + kh, j:j + kw] * flip_kernel)

Results

Comparison with scipy.signal.convolve2d

Both of my implementations match scipy.signal.convolve2d (mode="same") for every kernel.

Runtime Since the box kernel has a total of 81 entries, the two-loop version wins: taking the kernel-sized slice of the image requires much less overhead than running a Python loop over all 81 kernel entries for each pixel. However, for the Dx and Dy kernels, the four-loop version wins, because the overhead of the NumPy calls takes longer than running 3 iterations of the inner loop. In all cases, convolve2d wins, as it runs compiled C code rather than slow Python code.

Boundaries Due to the zero padding, each kernel creates a different edge behavior. The box kernel darkens all edges, because the zero padding is averaged in around the whole image. The Dx kernel brightens the left edge and darkens the right edge, since at the left edge the +1 weight lands on a real pixel and the −1 weight on a padded zero, while at the right edge it is the opposite. The same applies to the Dy kernel, except it brightens the top edge and darkens the bottom edge.

Part 1.2: Finite Difference Operator

In this section, I detected edges in the cameraman image using finite difference operators. Convolving the image with Dx = [1, 0, −1] and Dy = [1, 0, −1]T gives the partial derivatives in x and y, which respond to vertical and horizontal edges respectively. Combining them gives the gradient magnitude, which measures edge strength in any direction, and thresholding that gives a binary edge image.

Partial Derivatives & Gradient Magnitude

At each pixel, the two partial derivatives form the gradient vector, and its length is the gradient magnitude: √((∂I/∂x)2 + (∂I/∂y)2). 

dx = convolve2d(im, DX, mode="same")
dy = convolve2d(im, DY, mode="same")
grad_mag = np.sqrt(dx ** 2 + dy ** 2)

Binarized Edge Image

Threshold I chose a threshold of 0.25 on the gradient magnitude. This threshold gave enough definition on the main subject while mostly suppressing the noisy grass in the original image.

Tradeoff One major flaw is that it practically ignores the buildings in the background, as their edges are much lighter and less defined. This meant that while picking a threshold, I had to choose between a much noisier image where the buildings had definition, or a much cleaner image where the buildings were nearly non-existent. 

threshold = 0.25
edges = grad_mag > threshold

Part 1.3: Derivative of Gaussian (DoG) Filter

In 1.2, the gradient strengths of the grass and the background buildings overlapped, so no threshold on the finite differences could separate them. Here in 1.3, we first smooth the image with a Gaussian filter G, which averages out the random pixel-to-pixel changes while keeping the real edges.

Parameters σ = 2, 13×13 kernel (size 6σ + 1), built with cv2.getGaussianKernel and an outer product with its transpose. Edge threshold = 0.05.

Blur, Then Differentiate

First, we convolve the image with the Gaussian to blur it. Then we convolve the blurred image with Dx and Dy and compute the gradient magnitude as we did in 1.2. 

sigma = 2
ksize = (sigma * 6) + 1
g = cv2.getGaussianKernel(ksize, sigma)
G = g @ g.T

blurred = convolve2d(im, G, mode="same")
dx = convolve2d(blurred, DX, mode="same")
dy = convolve2d(blurred, DY, mode="same")
grad_mag = np.sqrt(dx ** 2 + dy ** 2)
edges = grad_mag > 0.05

Differences from 1.2

Noise We are now able to create an edge image with much more definition and without most of the grass noise found in 1.2. There are far fewer isolated pixels in the grass, and the outlines of the buildings in the back are much more defined. This is because the Gaussian averages out the grass noise, while the real edges survive since they are larger and more consistent.

Edge thickness The edges are also much thicker, since the blur spreads each edge over more pixels and the lower threshold keeps more of that spread.

Derivative of Gaussian Filters

Since convolution is associative, (I * G) * Dx = I * (G * Dx). So we can instead convolve the Gaussian with Dx and Dy once, creating the derivative of Gaussian (DoG) filters. We then convolve the image with these filters and compute the gradient magnitude as in 1.2. The DoG filters are built once on the small kernel, so the image itself only needs one convolution per direction. 

dog_x = convolve2d(G, DX, mode="full")
dog_y = convolve2d(G, DY, mode="full")
dx = convolve2d(im, dog_x, mode="same")
dy = convolve2d(im, dog_y, mode="same")
dog_grad_mag = np.sqrt(dx ** 2 + dy ** 2)

print(np.allclose(grad_mag[10:-10, 10:-10], dog_grad_mag[10:-10, 10:-10]))  # True

Verification The gradient magnitudes from both methods are equal (np.allclose returns True) everywhere except the outermost 1-pixel border of the image. The DoG filters are 13×15 (x) and 15×13 (y), shown below enlarged 20×.

Part 2.1: Image "Sharpening"

To sharpen an image, we first blur it with a Gaussian. This acts as a low-pass filter, removing the high frequencies from the original image. If we then subtract the blurred image from the original, we are left with only the high frequencies. By adding a scaled amount (α) of these back to the original image, we get an output image with the high frequencies emphasized, which makes it look sharper.

Unsharp Mask Filter

These steps can be combined into a single convolution. Written out, sharpening is f + α(f − f * G). To pull out f, we rewrite it as f * e, where e is the unit impulse: a kernel that returns the same image when convolved with it. This gives us f * ((1 + α)e − αG), so we can build this one kernel, the unsharp mask filter, and convolve the image with it once. I used σ = 2 (13×13 kernel) and α = 1, and the single-filter result matched the step-by-step version exactly. 

blurred = conv_color(im, G)
high = im - blurred
sharpened = im + alpha * high

e = np.zeros(G.shape)
e[ksize // 2, ksize //2] = 1
unsharp = (1 + alpha) * e - alpha * G
sharpened_2 = conv_color(im, unsharp)

print(np.allclose(sharpened_2, sharpened))  # True
